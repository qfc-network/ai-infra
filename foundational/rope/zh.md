# 旋转位置编码（RoPE）

- **作者 / 机构**：苏剑林、陆宇、潘胜丰、文博、吴云芳（追一科技）
- **发表时间**：2021-04 / RoFormer 论文，arXiv:2104.09864
- **链接**：[论文](https://arxiv.org/abs/2104.09864) · [代码](https://github.com/ZhuiyiTechnology/roformer)

## 一句话总结

RoPE 通过在注意力点积之前对查询向量和键向量的二维子空间施加旋转来编码位置信息。旋转的设计保证了旋转查询与旋转键的内积只依赖于它们之间的**相对位置**，而非绝对位置。零额外参数，无需位置嵌入查找表，不改变值（V）的传播路径。该操作是逐元素的，对内核友好：FlashAttention 2+ 将 RoPE 融合进注意力内核。所有主要开源大模型——LLaMA、Mistral、Gemma、DeepSeek、Qwen——都使用 RoPE。长上下文扩展方案（位置插值 PI、YaRN）通过调整旋转频率，在无需从头重训的情况下将上下文长度外推到训练长度之外。RoPE 是基础设施：在前向传播中不可见，参数量为零，而 θ 底数已成为现代大模型设计中的关键超参数轴。

## 背景与动机

### Transformer 与位置信息

原始 Transformer 注意力是置换不变的：同一组 token 以不同顺序输入，注意力分数完全相同（忽略掩码）。位置信息必须显式注入，问题在于如何注入。

### 已有方案及其缺陷

**可学习的绝对位置嵌入（BERT、GPT-2）**
在位置 m 处为 token 嵌入加上可学习向量 e_m。在训练长度内简单有效。缺陷：嵌入表大小固定，模型无法泛化到训练中从未见过的位置。对于训练最大长度 4096 的模型，位置 m=4097 是分布外输入。

**正弦绝对位置编码（原始 Transformer）**
将固定的正弦函数值加到 token 嵌入上。无学习参数，外推能力略优于可学习嵌入。但仍是绝对编码：模型须从绝对位置推断相对位置，既间接又不精确。

**相对位置偏置（T5、Shaw 等）**
根据查询位置 m 与键位置 n 的相对偏移（m-n），为注意力 logit 加上可学习的标量偏置。直接编码相对位置，实践中效果良好。缺陷：偏置在 QK 点积之后加入，与 FlashAttention 分块 SRAM 计算不兼容——每个分块都需访问所有相对偏移，破坏了 FlashAttention 高效性依赖的分块局部计算。

**ALiBi（Press 等，2021）**
从注意力 logit 中减去与相对距离成线性关系的量：score(m,n) → score(m,n) − λ·|m-n|，λ 为头特定常数。简洁、无参数、长度泛化性优于绝对嵌入。缺陷：ALiBi 在 QK 点积之外对 softmax 进行数值修改，无法融合进 FlashAttention 的标准注意力内核路径；线性衰减是强归纳偏置，在部分任务上质量不如相对位置编码。

**需求总结**

大型 LLM 的位置编码需同时满足：
1. 在 QK 点积中编码相对位置（而非仅绝对位置）。
2. 零学习参数——位置信息不应占用参数预算。
3. 内核友好——须可融合进 FlashAttention 的分块计算。
4. 精确注意力值——注意力分布无近似。
5. 自然的长度泛化能力，或有清晰的扩展路径。

RoPE 同时满足以上五点。

## 核心方法

### 旋转思想

对位置 m，RoPE 定义旋转矩阵 R_{Θ,m}，在点积之前对查询和键向量施加旋转：

```
f(q, m) = R_{Θ,m} · q
f(k, n) = R_{Θ,n} · k
```

位置 m 的查询与位置 n 的键之间的注意力分数变为：

```
score(m, n) = f(q, m)^T · f(k, n) = q^T · R_{Θ,m}^T · R_{Θ,n} · k = q^T · R_{Θ,(n-m)} · k
```

这是核心恒等式：**R_{Θ,m}^T · R_{Θ,n} = R_{Θ,(n-m)}**。点积只依赖相对位置（n-m），满足条件（1），同时无需任何逐位置参数，满足条件（2）。

### 旋转矩阵

R_{Θ,m} 是 d/2 个独立 2×2 旋转矩阵的块对角矩阵：

```
R_{Θ,m} = block_diag([R(m·θ_1), R(m·θ_2), ..., R(m·θ_{d/2})])
```

每个 2×2 块 R(φ) 为：

```
R(φ) = [[cos(φ), -sin(φ)],
         [sin(φ),  cos(φ)]]
```

旋转频率定义为：

```
θ_i = 10000^{-2(i-1)/d}，i = 1, 2, ..., d/2
```

这与正弦位置编码（底数 10000）的几何级数相同，但不是加到 token 嵌入上，而是作为旋转施加到 Q 和 K 上。

**几何解释**：d 维向量中的每对维度（第 2i-1 维和第 2i 维）各自所在一个独立的二维平面。当 token 处于位置 m 时，RoPE 将该平面旋转角度 m·θ_i。低频维度（i 大，θ_i 小）旋转缓慢——编码粗粒度位置；高频维度（i 小，θ_i 大）旋转快速——编码精细的局部位置。

### 实现

实践中从不显式构造块对角矩阵。只需将 d 维查询向量拆分为 d/2 个相邻对 [q_{2i-1}, q_{2i}]，然后施加：

```
q'_{2i-1} = q_{2i-1} · cos(m·θ_i) - q_{2i} · sin(m·θ_i)
q'_{2i}   = q_{2i-1} · sin(m·θ_i) + q_{2i} · cos(m·θ_i)
```

纯逐元素操作（交错的 cos/sin 乘加）。无矩阵乘法。对键同样施加相同操作。值（V）不变。FlashAttention 2 在分块内核中、计算注意力分数之前就完成 RoPE——无需额外内存带宽。

### θ 底数作为超参数

默认 θ 底数为 10,000（原始论文）。它决定了每个频率的有效波长：

- 最长波长（第 d/2 个维度对，旋转最慢）完成一个周期需 2π/θ_{d/2} = 2π·10000^{(d-2)/d} 个位置。
- 对 d=128：最长波长 ≈ 2π·10000^{126/128} ≈ 62,000——模型可区分约 62,000 以内的位置。
- 上下文长度超过约 8,000–16,000 时，高频维度会多次绕回，导致位置混淆。

设置更大的 θ 底数可延长有效波长。Llama 3 的 8k–128k 上下文变体使用 θ=500,000；许多长上下文模型使用 θ=1,000,000（1M）。更大的 θ 底数需要重训练或微调，但可提供原生长上下文能力。

### 长上下文扩展方案

**位置插值（PI，Chen 等，2023）**

对于长度 L' > L 的序列，不使用位置索引 0, 1, ..., L'-1，而是将其缩放为 0, L/L', 2L/L', ..., (L'-1)·L/L'。这将扩展窗口内的任意位置映射回训练位置范围 [0, L]。缩放因子为 L/L'。

优点：实现极简——仅需一行代码对位置索引乘以缩放因子。零新增参数。
缺点：对所有频率均匀压缩。高频维度（θ_i 小，旋转快）对局部 token 顺序最为重要，将其压缩意味着高频维度现在只能分辨更粗粒度的位置差异。在极长上下文上质量下降，尤其是需要精确局部 token 排序的任务。

**YaRN（Peng 等，2023）**

YaRN（Yet Another RoPE extensioN）使用频率相关缩放：对不同频率段施加不同缩放因子。

- 高频（θ_i 大）：插值幅度小——这些维度编码局部位置，须尽量保留。
- 低频（θ_i 小）：插值幅度大——这些维度编码全局位置，对缩放有更强的容忍性。
- 中频：在两种策略之间线性过渡。

YaRN 还对注意力 softmax 施加温度校正，以补偿扩展长度下 RoPE 修改向量的范数变化。效果：在训练于 4k 上下文的模型上，仅通过微调（无需完整重训）即可在 32k–128k 上下文上实现近乎无损的困惑度。

**LongRoPE（微软，2024）**

进一步优化：通过在困惑度目标上做进化搜索，分别为不同频率段优化缩放因子。用于 Phi-3，在 128k+ 上下文上质量优于 YaRN。

## 工程权衡

| 决策 | 收益 | 代价 |
|---|---|---|
| 绝对位置嵌入 | 实现简单；训练长度内质量最好 | 无长度泛化；嵌入表大小是上下文的硬上限 |
| 正弦绝对位置编码 | 无学习参数；外推能力略优于可学习嵌入 | 仍是绝对编码；相对位置须间接推断 |
| T5 相对偏置 | 真正的相对位置编码；中等上下文效果好 | 与 FlashAttention 分块计算不兼容；内存开销与 seq_len² 成正比 |
| ALiBi | 简单（只加标量偏置）；无参数；线性衰减提供归纳偏置 | 在 QK 点积之外修改——无法融合进 FlashAttention；线性衰减在部分任务上损害质量 |
| RoPE（默认，θ=10k） | QK 点积内相对位置；零参数；FlashAttention 可融合；精确注意力 | 上下文长度远超 8k 时频率绕回，需扩展方案 |
| 大 θ 底数（500k–1M，Llama 3） | 原生更长有效波长；无需插值扩展即可支持长上下文 | 需要重训练；短上下文绝对位置区分度略有下降 |
| 位置插值 | 实现极简；零新增参数；微调即可扩展上下文 | 对所有频率均匀压缩；极长上下文质量下降 |
| YaRN 频率相关缩放 | 32k–128k 上近乎无损；优于 PI；只需微调 | 超参数更多（每频率段的缩放因子、温度）；需要仔细校准 |

## 实验结果

**RoFormer（Su 等，2021）**：在中文 NLP 基准（文本分类、问答、自然语言推理）上评估。使用 RoPE 的 RoFormer 在各任务上均优于正弦和可学习绝对位置嵌入。相对位置性质在较长序列上优势尤为明显，因为绝对位置的信息量随序列长度下降。

**位置插值（Chen 等，2023）**：仅用 1,000 步微调，将 LLaMA 7B–65B 扩展至 32k 上下文。在长上下文文档上，困惑度从接近随机水平（2k 训练模型测 32k 长度）降至近乎无损（与原生 32k 训练模型相差 5% 以内）。100k 上下文下，1,000 步微调的 PI 与原生 100k 训练模型相当。

**YaRN（Peng 等，2023）**：将 LLaMA 2 7B 和 13B 从 4k 扩展至 128k 上下文。128k 处困惑度与原生 128k 训练模型相差不到 0.1 bits/token。密钥检索准确率（合成长上下文任务）在 128k 处接近 100%。相同长度下，PI 的困惑度退化为 2–5 bits/token。

**Mistral 7B**：使用 θ=1,000,000 配合滑动窗口注意力，原生支持长上下文。无需训练后上下文扩展。

**Llama 3**：使用 θ=500,000，并在训练阶段采用渐进式上下文长度调度（8k → 32k → 128k）。上下文扩展作为训练方案的一部分，而非事后补救。

## 可复现性说明

HuggingFace Transformers 通过 `rope_theta` 配置参数暴露 RoPE。设置 `rope_theta=500000` 并在长序列上微调是上下文扩展的标准方案。

```python
from transformers import LlamaConfig
config = LlamaConfig(
    rope_theta=500000,           # θ 底数；默认为 10000
    max_position_embeddings=131072,  # 扩展后的上下文长度
)
```

HuggingFace Transformers 中的 `apply_rotary_pos_emb` 工具函数可将 RoPE 应用于查询和键张量：

```python
from transformers.models.llama.modeling_llama import apply_rotary_pos_emb
cos, sin = self.rotary_emb(value_states, position_ids)
query_states, key_states = apply_rotary_pos_emb(query_states, key_states, cos, sin)
```

**FlashAttention 2+**：RoPE 融合进注意力内核。`flash_attn_with_kvcache` 接受 `rotary_cos` 和 `rotary_sin` 张量，在内核内部施加——无需单独的传播过程，无额外内存带宽。

**从零实现**：约 20 行 PyTorch。预计算位置索引的 cos/sin 表，然后用交错模式逐元素施加到 Q 和 K 上。唯一的细节：相邻对的分组方式——[q0,q1,q2,q3,...] → 旋转 (q0,q1)、(q2,q3)、... 还是在 d/2 处切分头维度。不同实现使用不同约定；需确保 Q、K 和 KV 缓存使用相同约定。

**YaRN 实践**：通过 `rope_scaling` 配置在 `transformers` 库中可用：

```python
config = LlamaConfig(
    rope_theta=10000,
    rope_scaling={
        "type": "yarn",
        "factor": 32.0,              # 目标长度 / 训练长度
        "original_max_position_embeddings": 4096,
    }
)
```

## 综合评述

RoPE 是基础设施，而非技巧。它在前向传播中不可见——对优化器不引入任何可见计算，不直接修改损失函数的景观，不占用任何参数预算。但它是基础性的：θ 底数的选择现已成为大型 LLM 的主要设计超参数，决定模型原生上下文范围的重要性不亚于隐层维度或层数。

θ 底数的演变历史说明了看似微小的选择如何带来巨大的下游影响：

- θ = 10,000（原始）：适用于 2k–4k 上下文，约 8k 处开始绕回。
- θ = 500,000（Llama 3）：不需插值即可在 ~128k 内良好工作。
- θ = 1,000,000（Mistral）：进一步延伸有效范围；短上下文质量略有损失。

YaRN 是已训练小 θ 模型需要服务更长上下文时的实用升级路径。只需微调（无需重训），现在已成熟到可在 HuggingFace 中一行配置搞定的程度。训练时使用大 θ 底数，扩展时配合 YaRN——这是当前长上下文 LLM 的最佳实践。

一个尚未解决的矛盾：RoPE 本质上是序列化的——它根据 token 在输入中的顺序分配位置。这对自回归文本很自然，但对于具有二维或三维结构的模态（图像、视频）就显得不自然。2D-RoPE（部分视觉语言模型使用）对空间轴施加不同的旋转速率。随着多模态模型突破纯文本的边界，这一领域仍在积极探索之中。
